# ChemAtlas worksheet typesetting

## Engine decision

The proof placed 2008 Version A MCQ 17 and its five shared reactions on one page, ten MCQs from distinct source booklets on three pages, and 2005 FRQ 3 on two pages. Inspection caught a clipped stem on 2018 MCQ 20 and a neighboring source footer below 2023 MCQ 6. The production fragments repair both. The proof exercised the chosen pipeline against actual Question Bank material. Alternative engines were evaluated using their documented capabilities and deployment constraints; standalone prototypes of those engines were not run.

| Technology | Evaluation |
| --- | --- |
| React-pdf | Supports reusable React components, fixed headers and numbering, native wrapping, text and SVG. Embedding original source PDF regions would require an additional overlay/composition path and a reliable way to export its exact placement coordinates. |
| Paged.js | Strong for HTML/CSS print templates, shared-context layout, and preview. A final PDF needs a compatible print backend. Original PDF fragments are not native HTML print blocks. |
| Puppeteer | A plausible PDF exporter for HTML/CSS, with print media, dimensions and font readiness. It requires managing Chromium or a remote browser service, plus a vector overlay strategy for original fragments. |
| Typst | Supports academic typography, math, automatic layout and PDF input images. It would introduce a native or WebAssembly compilation runtime, plus template and fragment delivery. |
| R/exams | Independent exercises, answer metadata, templates and multiple outputs provide a good architecture reference. R adds a separate runtime and offers no direct advantage for the existing React catalog. |
| PyMuPDF + PDF-LIB + PDF.js | Selected. Offline preparation retains vetted original content. A single browser-side PDF-LIB typesetter lays out and emits the file. The existing PDF.js preview consumes those exact bytes. No additional runtime dependencies or compilation service. |

## Layers

1. **Extraction.** Run `python research/build-worksheet-fragments.py` with PyMuPDF to regenerate the content manifest and fragment bank. The script joins existing Question Bank IDs to reviewed coordinates and manually verified text. It removes content outside crop boundaries and avoids rewriting complex chemistry. The compiled bank stores 84 reusable regions for 83 questions. Scans keep their original raster material.
2. **Layout.** The WorksheetContent model stores paragraphs, choices, tables, referenced shared contexts and diagram/source regions. The typesetter draws document headers, section labels, numbered question blocks, answer choices, diagrams, FRQ response lines and page footers. MCQ prompts and choices stay together. Multipart FRQs may break at their reviewed region boundaries and get continuation labels. The cursor in `worksheet-pdf.ts` is authoritative for page and coordinate placement.
3. **Export.** PDF-LIB embeds cropped forms directly into newly formatted sheets. The viewer and download link share the generated bytes. The existing paper sizes, margins, citations, answer keys and optional reference tables remain available. Whole pages are used only for the optional reference-table appendix.

The structured chemistry notation supports explicit subscripts and superscripts. Complex equations, tables and figures are kept as original source material. The current batch has 83 question objects; all catalog entries can still be selected, but entries without reviewed printable content block question export and are identified by name. A source page being readable in Question Bank does not establish where a worksheet crop should begin or end. Some source fragments with inseparable numbers retain them in addition to worksheet numbering.

## Verification

Run `node --import tsx scripts/verify-worksheet-export.mts [output-directory]` with the checkout dependencies available. Tests cover document page counts and order, exclusion of nearby stems from shared contexts, source bounds, a multipart FRQ, mixed A4 landscape with appendix and answer key, and errors for unresolved content. The timed 60-question scenario measures generation in Node with cached local input. It does not include network transfer, browser preview time or download time.
